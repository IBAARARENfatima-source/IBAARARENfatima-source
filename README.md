## Projets sélectionnés

### [SmartMaint](https://github.com/IBAARARENfatima-source/gmao) · Maintenance industrielle

Une GMAO développée en équipe pendant mon stage chez **SNOP, Groupe FSD**. J'ai travaillé sur l'API Spring Boot, l'interface React/TypeScript, la gestion des accès avec JWT, la conteneurisation Docker, l'infrastructure Azure avec Terraform et le pipeline CI/CD GitHub Actions. Le projet intègre aussi un assistant RAG fondé sur l'historique des pannes.

### CityPulse · Événements locaux

Une plateforme développée en équipe pour découvrir des événements et lieux proches sur une carte, publier du contenu et interagir avec la communauté. Elle réunit une interface React, cinq microservices Spring Boot, PostgreSQL et un déploiement conteneurisé avec Docker, Kubernetes et Terraform.

### [Classification de signaux ECG](https://github.com/IBAARARENfatima-source/classification-ecg-ptb-xl) · Deep learning

Projet de classification d'ECG à 12 dérivations en cinq catégories diagnostiques à partir de **PTB-XL**. Le notebook filtre et normalise les signaux, puis compare CNN 1D, CNN optimisé, BiLSTM, CNN-BiLSTM et ResNet1D sur un jeu de test séparé. Il présente les scores d'accuracy et de F1, les courbes d'apprentissage et les matrices de confusion.

### [Gestion des Notes](https://github.com/IBAARARENfatima-source/Gestion-Notes) · Application web universitaire

Projet développé en équipe selon une démarche agile Scrum : fonctionnalités priorisées, tâches réparties entre les membres et progression par itérations. L'application organise les classes, groupes, matières et affectations. Les enseignants saisissent les notes de TP, projet et contrôles ; les moyennes sont calculées selon les coefficients. L'espace étudiant présente un bulletin avec des données de démonstration. Stack : Spring Boot, Next.js et PostgreSQL.

### [FoodPlanner](https://github.com/IBAARARENfatima-source/FoodPlanner) · Planification de repas

Une application Android réalisée en équipe pour composer des menus selon les préférences et restrictions alimentaires, puis générer automatiquement les listes de courses correspondantes.

### [Data-Driven Decision Making](https://github.com/IBAARARENfatima-source/Data-Driven) · Analyse e-commerce

Un projet mené en équipe autour de données de transactions et de profils clients : indicateurs de vente, segmentation, modèles de prédiction et tableau de bord Streamlit pour éclairer les décisions marketing.

### [Business Performance Dashboard](https://github.com/IBAARARENfatima-source/business-performance-dashboard) · Power BI

Un tableau de bord réalisé en équipe pour suivre les ventes, la rentabilité et les tendances par produit et par région. Les visualisations et indicateurs Power BI facilitent l'analyse des performances commerciales.
